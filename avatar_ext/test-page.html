🤖 Avatar Extension Test Page

📋 Instructions

  1. Load the extension in Chrome (chrome://extensions/ → Developer mode → Load unpacked)
  2. Refresh this page after loading the extension
  3. Look for the avatar in the top-right corner of the page
  4. Click the buttons below to test various functions

🔍 Quick Tests

🎯 Expected Behavior

  • Avatar should appear in the top-right corner with a Python logo
  • Buttons should be visible:
    • 🎤 Microphone (blue)
    • 🔊 Test TTS (green)
    • 🎵 ElevenLabs Config (orange)
    • 🎭 Emotion Test (yellow)
    • 📌 Save Position (blue)
  • Avatar should be draggable (click and drag to move)
  • Speech bubble should appear to the left of the avatar

🐛 Troubleshooting

If you don't see the avatar:
  • Check Chrome Extensions page - is the extension enabled?
  • Look for errors in the extension details page
  • Open browser console (F12) and look for error messages
  • Try reloading the extension and refreshing this page
